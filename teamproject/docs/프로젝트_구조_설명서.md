# 프로젝트 구조 설명서

> **프로젝트명**: teamproject (튜터-학생 매칭 플랫폼)  
> **프레임워크**: Spring Boot 3.5.10 / Java 23  
> **빌드 도구**: Gradle  
> **데이터베이스**: MySQL (`matching`)

---

## 1. 기술 스택

| 분류 | 기술 |
|------|------|
| **Backend** | Spring Boot 3.5, Spring Security 6, Spring MVC |
| **ORM / SQL** | MyBatis 3.0.5, Spring Data JPA |
| **Template** | Thymeleaf + Layout Dialect |
| **인증** | JWT (jjwt 0.12.5), OAuth2 (소셜 로그인) |
| **결제** | Toss Payments API |
| **AI** | OpenAI Java SDK 4.18.0 |
| **DB** | MySQL (mysql-connector-j) |
| **API 문서** | Springdoc OpenAPI (Swagger UI) |
| **기타** | P6Spy (SQL 로깅), PageHelper (페이징), Lombok, Jackson JSR310 |

## 4. 계층별 상세 설명

### 4.1 API 컨트롤러 (`api/`)

REST API 엔드포인트를 제공하는 `@RestController` 클래스들.

| 파일 | 역할 |
|------|------|
| `AuthApiController` | 로그인, 회원가입, 토큰 갱신, 비밀번호 변경, 회원 탈퇴 |
| `UserController` | 사용자 정보 조회/수정, 중복 체크 |
| `TutorController` | 튜터 등록, 프로필 CRUD, 마이페이지, 튜터 목록/상세 |
| `TutorAvailabilityController` | 튜터 수업 가능 시간 관리 |
| `TutorTimeRangeController` | 튜터 기본 시간대 설정 (요일별 반복) |
| `BookingController` | 수업 예약 생성, 확정, 취소, 완료 처리 |
| `LessonController` | 수업(레슨) CRUD |
| `ReviewController` | 리뷰 작성, 수정, 삭제 |
| `TossPaymentApiController` | Toss Payments 결제 승인/취소 |
| `SubjectController` | 과목/과목 그룹 관리 |
| `LanguageFieldController` | 언어 분야 목록 조회 |
| `AdminApiController` | 관리자 API (사용자 관리, 튜터 승인, 정산 등) |
| `AdminInquiryApiController` | 관리자 문의/티켓 관리 |
| `InquiryController` | 사용자 문의 등록/조회 |
| `TutorMessageController` | 튜터-학생 메시지 송수신 |
| `TutorStudentNoteController` | 튜터 학생 관리 노트 |
| `AiAssistantController` | AI 수업 요약, 숙제 생성 (OpenAI) |
| `KoreanProverbController` | 한국어 속담 게임 API |

```
    │
    ▼
JwtAuthenticationFilter          ← 모든 요청에서 JWT 토큰 검증
    │
    ▼
SecurityFilterChain              ← URL별 인가 규칙 적용
    │
    ├── /api/auth/** → permitAll (로그인, 회원가입)
    ├── /admin/** → ROLE_ADMIN 필요
    ├── /api/bookings/** → ROLE_USER, ROLE_TUTOR, ROLE_ADMIN
    ├── /api/tutors/me/** → ROLE_USER, ROLE_TUTOR, ROLE_TUTOR_PENDING
    └── 기타 → authenticated
```

- **JWT 토큰**: Access Token + Refresh Token 방식
- **OAuth2**: 소셜 로그인 지원 (성공 시 JWT 발급)
- **세션**: `IF_REQUIRED` (OAuth2 플로우에서만 사용)
- **CSRF**: API 경로(`/api/**`)에 대해 비활성화

## 8. 주요 비즈니스 플로우

### 8.1 튜터 등록 플로우

```
register (인트로) → register1 (기본 정보 입력)
    → register2 (서류 업로드) → register3 (스케줄 설정)
    → 관리자 승인 대기 (ROLE_TUTOR_PENDING)
    → 관리자 승인 → ROLE_TUTOR 부여
```

### 8.2 수업 예약 플로우

```
학생: 튜터 목록 → 튜터 상세 → 시간 선택 → 예약 요청
    → 튜터 확정 → 결제 (Toss Payments) → 수업 진행
    → 수업 완료 → 리뷰 작성
    → AI 수업 요약 / 숙제 생성 (선택)
```

### 8.3 결제 플로우

```
예약 확정 → checkout 페이지 → Toss Payments 위젯
    → 결제 승인 API 호출 → success/fail 페이지
```
